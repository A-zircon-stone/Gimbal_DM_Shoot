# 实时文字输出（仅反馈验证，不驱动电机）

## 使用

重新构建/下载GM6020_Feedback，连续运行，不要暂停调试器。
默认每100ms一帧（10Hz），USART1和USB均输出FireWater CSV，方便VOFA绑定：

1. C板自身USB接口 → USB数据线 → 电脑的USB虚拟串口，输出FireWater CSV（详见vofa-cube.md）。
   反馈模式下暂停旧VISION二进制报文，避免文字与二进制混合。
   串口助手选该设备的COM口，文本/ASCII显示，可设115200、8N1、无流控。
   USB CDC的波特率设置不决定实际USB速率。
   DAPLink的USB口不是C板USB CDC接口，不能保证两者共享同一个COM口。
2. USART1：PA9 TX → USB-TTL适配器RX，板GND → 适配器GND。
   默认发送att:数字CSV，VOFA+选FireWater引擎；接线和波特率无需因协议改变而调整。
   使用3.3V逻辑电平、115200 baud、8数据位、1停止位、无校验、无流控。
   只收日志无需连接适配器TX、板PB7 RX；不要将适配器5V接入信号引脚。
   USART3/USART6继续保留给旧遥控链路，不挪用。

没有新增USB设备时，检查数据线是否支持数据传输、接口是否为C板自身USB、驱动/设备管理器。
不要假定固定COM号，插拔C板USB辨认新增的端口。程序暂停时停止打印属正常。

## 字段

保留的人工标签日志示例（仅PrintUart1FireWater=false时USART1输出；默认是att:数字CSV）：

```text
t=1234 N=1000 IMU=1 R=-12.25 P=+8.50 Y=+179.00 gx=-1.500 gy=+0.000 gz=+0.000 EY=8191 EP=123 rpmY=-100 rpmP=0 OY=1 OP=1
```

- t：HAL毫秒计数；N：已完成并发布的INS帧计数，持续增长才能表明任务在更新。
- IMU：有已发布帧、年龄<=100ms且六个浮点测量有限时为1，不代表融合精度已验证。
- R/P/Y：直接来自INS.Roll/Pitch/Yaw，单位度，未套用未知机械轴符号。
- gx/gy/gz：传感器轴角速度，单位rad/s，不等同于欧拉角变化率。
- TY：从融合四元数计算的传感器Y轴连续倾斜辅助角，单位度，绕Y转动时不在±90°折返；
  TV=1表示本帧几何投影/时效有效，0时保留旧角值供诊断，不可作为新测量。
  它不是通用机械Pitch。要求Y轴对应机械Pitch且不接近重力方向；没有确认安装方向前不参与控制。
  按INS连续帧解绕，失效后重建单圈参考；不能据恢复后的值推断失效期间圈数。
- EY/EP：Yaw ID1 / Pitch ID2 的单圈编码器，范围0..8191，有回绕。
- rpmY/rpmP：电机原始轴转速rpm。
- OY/OP：对应电机收到过有效反馈且反馈年龄<=100ms时为1，失联后为0。
  离线时编码器保留上一次值，不能当成新反馈。

## 方向测试

支撑好Pitch，C板固定在最终位置且随Pitch运动；保持无输出固件，不接其他控制器/PWM命令。
先静置，缓慢抬头、停稳，看R/P谁主要变化及正负；再单独向左转Yaw。
同时运动时看gx/gy/gz，停下后看角度。接近欧拉角奇异姿态时不能直接据R/Y判断独立机械轴。
复制一段日志并注明“静止/抬头/左转”，再决定闭环轴向映射。

当前重测只需：静置2秒，缓慢抬头10–20度、停稳；再单独向左转10–20度、停稳。
两段分别注明方向，不要混入往返动作或手动越过机械限位。先不使用旧R/P/Y直接闭环。

## 实现边界

- INS只在整帧更新后短临界区发布快照；采集、融合和CAN回调不调用格式化/打印。
- PRINT任务保持旧看门狗2ms调用频率，仅每100ms格式化一次。
- UART DMA与USB各用独立静态缓冲区；忙时丢弃该通道当前行，绝不等待发送结束。
- USB配置完成/类实例非空后才发送；USB TX忙时不覆盖其缓冲区。
- 目前USART1 TX只有PRINT一个调用方；后续新增打印必须统一调度，不能绕过所有权规则。
- USART1默认PrintUart1FireWater=true，不能再将旧标签文字当成当前默认格式。
- 主机测试覆盖文本格式、正负与单位字段、截断边界、NaN/Inf标记；
  固件编译通过不代表物理串口、USB拔插和实时周期已完成板测。
