# 云台通用双环 PID 重构

**目标：** 将 Yaw/Pitch 的专用单环算法替换为四个持久 `Pid_t` 对象，通用计算只位于 `Framework/PID`。
**依据：** 用户在本会话批准位置环、速度环分离，并明确要求清理 `DamiaoPitchPid.hpp`。
**环境：** STM32F407、C++17、FreeRTOS、CMake；在当前调试工程就地修改，原文件已备份到本会话 work 目录。

## 边界

- 保留使能、反馈检查、Pitch 角度范围、Yaw 可选限位、CAN 协议和既有扭矩范围。
- 不添加位置环速度限幅；通用 PID 默认不限输出，仅速度内环传入现有扭矩限制。
- Pitch 保留总输出含重力前馈的抗积分饱和及现有积分上限。
- 摩擦轮/M2006 保留原三参数 `Cal()` 的离散计算接口。
- 默认 Pitch 位置 P=100、速度 P=0.5；Yaw 位置 P=60、速度 P=0.5；其余增益为0，来自当前 PD 的等价分解。
- 复用既有在线接口：Pitch `kpp/kp/ki/kd`，Yaw `ykpp/ykp/yki/ykd`。`dm_kp/ki/kd` 作为 Pitch 速度环别名，在文档明确语义迁移。
- 本次不烧录，不改变发射模式，不增加测试动作/命令。

## 步骤

- [ ] 通用 PID：新增 `PidGains`、`PidLimits`、`PidInput`，`Pid_t::Calculate()` 使用真实dt、测量微分、前馈及条件积分；默认无限幅。测试周期变化、导数、前馈饱和、积分恢复、非法数据、实例独立和原Cal接口。
- [ ] 两轴：各声明位置/速度 `Pid_t`，目标保留在runtime快照；初始化/停止清理两环，在线增益不重置目标；删除 Pitch 专用控制器及重复历史块。
- [ ] 调参：集中配置两环增益；接通原位置P和速度PID串口入口，别名写入同一个邮箱保证接收顺序；快照增加目标角速度、两组增益。
- [ ] 测试：迁移真实runtime测试；确认默认输出与旧PD一致，两环反馈使用IMU，视觉/遥控/重启/Pitch重力处理和增益更新正确；串口真实解析测试覆盖新映射。
- [ ] 清理：删除 `DamiaoPitchPid.hpp` 及专用测试/构建项；用通用PID测试替代；更新现有状态打印及架构说明，标明当前链路与旧6020模块。
- [ ] 验证：主机全量CTest、STM32 Debug构建、差异检查和残留引用检查。
