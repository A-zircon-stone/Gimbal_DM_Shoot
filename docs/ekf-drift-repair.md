# 静止漂移排查与修正（未做本轮板测）

## 已确认的代码问题

1. BMI088启动校准耗时数秒，但INS_DWT_Count初值0。第一次DWT_GetDeltaT可能包括校准时间，
   相当于把数秒/十几秒作为一次姿态积分时长。现在INS_Init末尾重置计数，且拒绝dt<=0或>20ms。
2. EKF无视实际安装姿态，从单位四元数启动。现在首个有效加速度方向建立重力对齐姿态，
   初始Yaw选相对0；用户必须在启动校准期间保持静止。
3. 原代码把四元数修正向量第3项清零，注释称“不修正yaw”。q3不等于独立Yaw，
   已取消这种逐分量屏蔽。仅重力观测本来就没有绝对航向信息。
4. 一次牛顿invSqrt留下可见范数误差，且后验未统一归一化；只在VOFA发送副本归一化不能修复内部状态。
   现用sqrtf精确归一化，保持内部xhat/FilteredValue/q一致；反三角函数输入限幅。

这些改动不等于已证实解决了用户板上的全部温漂/残余零偏，也没有引入磁力计或绝对航向参考。
本轮没有把动态姿态直接锁为常数，没有自动猜测电机正向，也没有开启电机命令。

## 回归与模拟

- 使用实际QuaternionEKF.c和kalman_filter.c，主机测试仅替换MCU头和小矩阵运算后端。
  参考矩阵实现不是CMSIS-DSP逐位等价或性能测试。
- tests/ekf_drift_probe.cpp输入理想零角速度、恒定倾斜加速度，600000次1ms更新。
  logs/ekf-startup-before.txt与logs/ekf-startup-after.txt保留综合修复前后结果。
  原版从单位四元数启动，模拟600秒后Yaw约6.67度；修正后初末Yaw均约0，norm²约1。
  这是无噪声模拟结果，不能作为真实BMI088零漂指标。
- 自动测试包含六个静置面、任意倾斜静止、非法输入/超长dt、倾斜姿态下持续Yaw转动。
  还保留协议/编码器/辅助角测试，共13项。动态Yaw用例用于防止通过冻结姿态伪造“不漂移”。

## 新增诊断列（从0开始）

USART1与USB仍用FireWater，前0..20列不变，原四元数绑定不用重做。

|列|内容|单位|
|---|---|---|
|21..23|EKF内部估计的额外GyroBias X/Y/Z|rad/s|
|24..26|本轮预测实际使用的QEKF_INS.Gyro X/Y/Z|rad/s|
|27|BMI088温度|℃|
|28|本轮融合dt|s|
|29..31|本轮加速度XYZ|m/s²|
|32|滤波内部输出四元数范数|无|
|33|加速度模长|m/s²|

日志原7..9列已经扣除了BMI088驱动启动零偏，但还没有扣除EKF内部偏置，
不能仅凭7..9列接近0认定预测角速度接近0。21..23为本轮更新后的偏置，
24..26使用更新前偏置，两者可能有本轮微小差异。当前EKF仍只估计XY两维额外偏置。

## 板测步骤

重新构建/下载GM6020_Feedback，上电开始固定C板和整个云台底座，至少20秒不动。
之后再连续记录30秒完整att行，勿暂停调试器、勿移动底座。VOFA绑定保持scalar=0、XYZ=1/2/3。
比较TY与Yaw的变化，检查内部四元数范数约1、dt约0.001s、温度是否仍快速变化、
实际预测角速度是否接近0。温度稳定前的记录不能冒充恒温零偏效果。
本轮尚未验证实际温控状态、驱动校准超时是否使用了历史默认偏置；用新诊断数据继续区分。
