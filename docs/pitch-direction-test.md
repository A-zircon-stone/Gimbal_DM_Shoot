# Pitch 驱动方向短脉冲测试

## 当前测试配置更新

按用户要求，方向测试默认忽略编码器绝对限位和40计数位移限制；下文这些位置限制仅适用于显式构造`PitchDirectionTest{true}`的旧测试模式。
当前命令`current=2000`最长500ms，速度、反馈新鲜度、CAN失败、任务间隔和手动停止仍有效。
闭环映射的3900～6200机械范围及保护带未修改。测试模式可能撞到机械端点，操作者必须留足行程、支撑机构并准备切断电机电源。

本入口只用于确认 CAN1 上 GM6020 ID2 的原始命令正负方向，不是闭环控制。
复用原 CAN1 HAL 与 USART1 DMA-IDLE 调试接收，不改变旧 PID/MDO、温控、启动校准。
`FeedbackOnly=true` 保持不变，旧发送路径仍被禁用；独立测试入口是唯一新增发送例外。

## 操作

简化入口：正常运行时单独发送 `current=600` 或 `current=2000` 加换行，无需先arm，分别请求+600或+2000的电流给定脉冲，最长500ms后归零，保护可提前中止。
`pitch_pos`保留为同义命令，`current=0`等效于`pitch_stop`。只接受这两个固定current命令，不开放任意持续电流。
所有反馈、静止、限位及故障锁定条件不变，不是持续正电流命令；不得循环发送。

1. 托住/支撑 Pitch，清空运动空间，准备可立即切断电机供电的开关；不要夹住旋转件。
2. 下载 `build/Debug/2026_Balanced_Gimbal.elf` 后正常运行，不要在脉冲期间打断点、暂停或单步。
3. USART1 双向连接：PA9 TX→适配器RX，PB7 RX←适配器TX，共地，115200 8N1。
4. 用户给定机械范围3900～6200，EP须严格位于3950～6150保护带内，电机基本静止，IMU及两台CAN反馈有效。
5. VOFA发送框选择追加换行（LF或CRLF），关闭自动/循环发送。
6. 单独发送 `pitch_arm`，再在5秒内单独发送一次 `pitch_plus`。
7. 保存前后日志。不要自动连发，不要因未看到动作就增大命令。
8. `pitch_stop` 可随时请求软件停止。异常时优先切断电机供电。
9. 需要反向测试时，待静止后重新 `pitch_arm`，再 `pitch_minus`。

默认Idle不发送测试帧，不会因上电自动动作。请求测试后周期发送零值维持停车。
旧pitch命令保持±600，显式current=2000使用+2000（CAN_Demo原始电流给定，尚未核实到安培的换算）；最长500ms，不能串口任意更改幅值/时长。
状态机在GIMBAL任务每2ms执行；软件停止不能保证对抗调试暂停、MCU死机、断线、CAN总线故障或惯性滑行。
零电流给定也不是机械抱闸，Pitch重力下落仍需支撑。

## 中止条件

- IMU映射年龄超过20ms，或任一电机反馈年龄超过100ms。
- EP到达/超出3950～6150，或相对脉冲开始移动达到40计数（约1.76°）。
- 映射角速度绝对值达到0.35rad/s，或电机转速绝对值达到5rpm。
- 任务间隔超过10ms、CAN提交失败；Fault状态必须重启才可再次测试。
- Armed状态超时5秒，或条件失效，则取消武装。

这些阈值是保守的软件测试限制，不是已验证的制动距离或物理安全保证。
停止时取消尚在CAN邮箱中的旧脉冲并尝试发零；总线损坏时不能保证零命令送达。

## 遥测

原0～33列不变，追加：34状态，35原始命令，36本次EP变化。
状态：0闲置，1已武装，2运行，3完成，4拒绝，5故障锁定，6手动停止。
打印10Hz，应同时看运行/完成状态及EP/gy变化；保护提前中止时也可能看不到运行帧。状态完成不证明CAN实际传输成功或电机已执行。
正命令后EP减小、gy负表示正命令抬头；EP增大、gy正表示正命令低头。
没有可辨别运动时不能判定驱动方向。
